# Cloud AI Fire Detection and Alert System

## Project Overview

A distributed cloud-based AI fire detection and alert system deployed on OpenStack using YOLO and FastAPI.

## Project Category

Cloud-Based AI/ML Service

## Cloud Platform

OpenStack

## Architecture

Distributed

## Technologies

- OpenStack
- Python
- YOLO
- FastAPI
- Docker

## Project Goals

- Detect fire using an AI-based YOLO model.
- Deploy the AI service on OpenStack.
- Provide a cloud-based API for fire detection.
- Store detection results.
- Demonstrate scalability and reliability.
- Demonstrate cloud deployment, networking, and storage.
